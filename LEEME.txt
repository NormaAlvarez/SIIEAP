QUÉ CAMBIÓ
----------
Antes había dos apps separadas (`streamlit run app.py` para el diagnóstico
IDI-MIPG, y `streamlit run modulo_riesgo_piloto.py` para el piloto de
riesgo, cada una por su lado). Ahora hay un solo punto de entrada:

         📊 Diagnóstico IDI-MIPG (v6.1)
         🛡️ Administración y Gestión del Riesgo (piloto)
       Según lo que elija el usuario, ejecuta uno de los dos módulos de
       abajo. No contiene ninguna pantalla propia.

  diagnostico_idi_mipg.py
    -> Es EXACTAMENTE el contenido de su app.py anterior (las mismas 1469
       líneas, el mismo código, los mismos cálculos, ni una coma cambiada),
       solo que ahora envuelto en una función render_diagnostico_idi_mipg()
       para que el router pueda llamarlo. Sigue funcionando también solo:
           streamlit run diagnostico_idi_mipg.py

  modulo_riesgo_piloto.py
    -> Es el módulo de riesgo (10 pantallas + mapa consolidado, ya con
       las 5 instrucciones de la validación del 19-sep-2026 incorporadas),
       envuelto de la misma forma en render_modulo_riesgo(). También sigue
       funcionando solo:
           streamlit run modulo_riesgo_piloto.py

No se reescribió ni una pantalla ni un cálculo de ninguno de los dos
módulos para hacer esta integración: solo se les puso una "envoltura" de
función para que un mismo archivo (app.py) pueda decidir cuál mostrar.

CÓMO INSTALARLO
----------------
1. Copie los 3 archivos de la raíz de este paquete (app.py,
   diagnostico_idi_mipg.py, modulo_riesgo_piloto.py) a la raíz de su
   proyecto SIIEAP, REEMPLAZANDO el app.py que tenía antes (su contenido
   íntegro quedó preservado dentro de diagnostico_idi_mipg.py, no se
   pierde nada).
2. Copie la carpeta backend/ de este paquete sobre la carpeta backend/ de
   su proyecto (son los mismos archivos del módulo de riesgo que ya tenía
   instalados del zip anterior; se incluyen aquí de nuevo solo para que el
   paquete quede completo y autocontenido).
3. Ejecute:
       streamlit run app.py
   Debe abrir con el menú "Módulo" en la barra lateral. Por defecto se ve
   el Diagnóstico IDI-MIPG; al elegir "Administración y Gestión del
   Riesgo (piloto)" en la barra lateral aparecen las 10 pantallas del
   módulo nuevo, sin salir de la aplicación ni abrir otra pestaña.
